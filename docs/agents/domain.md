# Domain Docs

This is a single-context repository.

Before exploring, read the root `CONTEXT.md` and relevant ADRs under `docs/adr/`. Proceed silently when either location does not exist.

Use the glossary's canonical vocabulary in issues, proposals, tests, and implementation. Surface conflicts with existing ADRs instead of silently overriding them.

`CONTEXT.md` and ADRs are created lazily through domain modeling when terms or decisions are resolved.
